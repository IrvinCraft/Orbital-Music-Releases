# Orbital Music - Releases

Repositorio **público** que contiene SOLO los instaladores/binarios de [Orbital Music](https://github.com/IrvinCraft/Orbital-Music) (el código fuente vive en un repo privado).

La app consulta la API de releases de este repo para saber si hay actualizaciones y descargar el instalador correspondiente a su plataforma.

## Descargar la última versión

- **Windows**: usa el `.exe` del último release.
- Bajar siempre desde [Releases](https://github.com/IrvinCraft/Orbital-Music-Releases/releases/latest).
